# Magic: The Gathering Multiplayer Network Protocol (MTGNP) Reference

Welcome to the comprehensive reference guide for the MTGNP Machine Problem. This repository contains all the necessary documents and specifications required to complete the project successfully.

## Table of Contents
1. **[Instructions and Rubric](01_Instructions_and_Rubric.md)**: Contains the project objectives, deliverables, grading rubrics, AI usage policies, and what is allowed/not allowed.
2. **[MTGNP RFC 0001 (Protocol Specification)](02_MTGNP_RFC_0001.md)**: The formal specification for the MTGNP protocol, detailing the client-server architecture, message framing, game lifecycle, turn structure, priority handling, and JSON PDU schemas.
3. **[Master Card List](03_Master_Card_List.md)**: The comprehensive table of the 58 fixed, pre-defined cards in the MTGNP 1.0 card set, including their colors, mana costs, stats, and simplified effects.

Use these files as your "holy grail" reference to achieve a perfect 100/100 points on the machine problem. Make sure to adhere to the strict protocol guidelines and the verbose mode prerequisites detailed in the instructions!
